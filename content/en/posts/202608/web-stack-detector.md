Chrome: Pending review

![Web Stack Detector](https://images.elecmonkey.com/articles/202608/web-stack-detector.webp)

It detects the frontend framework, UI library, and build tool used by the current website, including React, Vue, Next.js, Vite, webpack, and Rspack. Once detection is complete, the extension icon in the toolbar changes to the logo of the detected technology. Click the icon to see more details, including the specific version and the evidence behind the result.

The project is open source on [GitHub](https://github.com/swwind/web-stack-detector).
